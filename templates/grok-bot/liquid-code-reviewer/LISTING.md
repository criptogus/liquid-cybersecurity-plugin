## Full description
Building a product with a coding agent? Add a focused review step before you
ship. Liquid Code Reviewer helps you submit selected, authorized JS/TS files,
read the actual findings and coverage limits, and prepare a minimal fix plan.

New users can start with a separate free website trial: one file up to 12,000
UTF-8 bytes per verified account. Existing assessment users can connect Liquid
through their own OAuth and approved assessment scope. Custom MCP connections
must be configured after importing this template; they do not transfer from
the creator's account. Host-app access and usage follow the host's own plan.

This Bot works on demand. It does not run code or live pentests, spend credits,
edit projects, create or merge PRs, or deploy automatically. Findings are
candidates, not confirmed exploits. No result certifies production safety.
